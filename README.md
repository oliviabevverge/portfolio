# Portfolio Website

This repository contains the source code for my personal portfolio website. The site is a static front-end built with HTML and CSS to showcase my skills, projects, experience, and contact information. It is intended to be hosted on GitHub Pages or any static site host.

## About

This portfolio presents:

- an about section with background information
- a skills section
- a list of projects
- professional experience and awards
- additional personal interests
- a contact section

The design emphasizes readability, responsive layout, and clean typography. The portfolio serves as a personal introduction to potential employers, collaborators, or future classmates.

## Live Demo

https://oliviabevverge.github.io/portfolio

## Features

- responsive design for desktop and mobile
- navigation bar linked to page sections
- portfolio of projects
- experience and award showcase
- contact information
- styled with custom CSS

## Tech Stack

- HTML
- CSS

No JavaScript frameworks or build tools — this is a static HTML/CSS site.
